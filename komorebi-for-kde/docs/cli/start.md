```text
Start komorebi as a background process

Usage: start [OPTIONS] [-- <KOMOREBI_ARGS>...]

Arguments:
  [KOMOREBI_ARGS]...
          Arguments to pass to komorebi, after a `--`: `komorebic start -- --log-level debug`

Options:
  -c, --config <CONFIG>
          Path to a static configuration JSON file

  -h, --help
          Print help

```
