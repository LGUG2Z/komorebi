```text
Key bindings: KDE global shortcuts from a key binding file, and the keys of the daemon

Usage: hotkeys <COMMAND>

Commands:
  compile  Plan the bindings of a key binding file, and write those that are static shortcuts as KDE
           shortcut files
  state    Show the keys komorebi has registered with KDE, and what the engine of the daemon is
           doing
  reload   Have the daemon read its key binding file again
  release  Unregister every key komorebi has registered with KDE, whether a daemon runs or not
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help

```
