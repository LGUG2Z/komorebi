# adjust-container-padding

```
Adjust container padding on the focused workspace

Usage: komorebic adjust-container-padding <SIZING> <ADJUSTMENT>

Arguments:
  <SIZING>
          Possible values:
          - increase: Increase
          - decrease: Decrease

  <ADJUSTMENT>
          Pixels to adjust by as an integer

Options:
  -h, --help
          Print help (see a summary with '-h')

```
