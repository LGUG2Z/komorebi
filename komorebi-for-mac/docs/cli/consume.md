# consume

```
Take the window on one side into the focused column

Left takes the last window of the column on the left to the top of the focused column, and right
takes the first window of the column on the right to the bottom of it. Up and down do nothing. Only
the Scrolling layout has columns of several windows, so this does nothing in the other layouts.

Usage: komorebic consume <OPERATION_DIRECTION>

Arguments:
  <OPERATION_DIRECTION>
          [possible values: left, right, up, down]

Options:
  -h, --help
          Print help (see a summary with '-h')

```
