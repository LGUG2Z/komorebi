# toggle-column-stack

```
Stack the windows of the focused column, or spread a stack out into a column

A column of several windows becomes one stack of all of them, which takes the height of the column
and shows one window at a time, and the usual stack commands work on it. A stack becomes a column
with a window in each slot, in the order of its tabs. Only the Scrolling layout has columns of
several windows, so this does nothing in the other layouts.

Usage: komorebic toggle-column-stack

Options:
  -h, --help
          Print help (see a summary with '-h')

```
