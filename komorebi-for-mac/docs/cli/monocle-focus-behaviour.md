# monocle-focus-behaviour

```
Set the behaviour when focusing in a direction while a monocle container is active

Usage: komorebic monocle-focus-behaviour <BEHAVIOUR>

Arguments:
  <BEHAVIOUR>
          Desired monocle focus behaviour

          Possible values:
          - cycle: Cycle the monocle container to the next/previous container in the workspace
          - no-op: Do nothing, allowing focus to fall through to cross-monitor logic

Options:
  -h, --help
          Print help (see a summary with '-h')

```
